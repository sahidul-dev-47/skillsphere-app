## 🎓 About SkillSphere

Managing online learning often means fragmented tools and slow, clunky experiences. **SkillSphere** solves this with a unified, high-performance Learning Management System (LMS) where learners can browse courses, dive into detailed curriculum breakdowns, manage their profiles, and navigate a fast, server-rendered interface end-to-end.

Built for **independent learners, students, and educators** who need a platform that feels fast and modern, not like a legacy course portal.

## 🚀 Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/sahidul-dev-47/skillsphere-app.git
cd skillsphere-app
npm install
```

Create a `.env` file in the root directory:

```env
NEXT_PUBLIC_API_URL=        # Your backend API endpoint
MONGODB_URI=                 # Your MongoDB connection string
BETTER_AUTH_SECRET=          # Your authentication secret key          
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🚧 Known Limitations & Roadmap

- Payment gateway integration is in a sandbox/testing state
